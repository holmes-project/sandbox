CRUD ／ データを扱う4つの基本操作

CRUDってなに？ データの「作る・読む・変える・消す」

ひとことで言うとCRUD ＝
データに対してできる4つの基本操作の頭文字。
ほとんどのアプリは、この4つの組み合わせでできている
C作る R読む U変える D消す
CCreate作成

新しいデータを作って追加する

SNS新しく投稿する通販会員登録する連絡先友だちを登録
RRead読み取り

今あるデータを探して見る（中身は変えない）

SNSタイムラインを見る通販商品を検索する連絡先名前で探す
UUpdate更新

今あるデータの中身を書き換える

SNS投稿を編集する通販住所を変更する連絡先電話番号を直す
DDelete削除

いらなくなったデータを消す

SNS投稿を削除する通販退会する連絡先登録を消す
やってみようメモアプリで CRUD
自動で C → R → U → D を実演します。止めると自分で操作できます。
