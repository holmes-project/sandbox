AP SERVER I/O ／ リクエストを受けて、JSONを返す

APサーバの入出力 ― 何を受け取り、何を返す？

ひとことで言うとAPサーバ ＝
リクエストを受け取り、プログラムで処理して、
結果を JSON で返す「処理係」のサーバ
入力：リクエスト▶⚙️ 処理▶出力：JSON
1リクエストの中身（入力）例をクリックで切り替え
①メソッド ＋ URLクライアントが叩くURL
②ヘッダーリクエストの「添え状」
③ボディ送りたいデータ本体（JSON）
★メソッドの意味（CRUDと対応）
GET取得する（R） POST作成する（C） PUT / PATCH更新する（U） DELETE削除する（D）
💡 同じURLでもメソッドが違えば別の処理になります
GET /api/orders → 注文の一覧　／　POST /api/orders → 新しい注文
2リクエストとレスポンスの流れ
🧑‍💻 📱クライアント ブラウザ・スマホアプリ
（Webサーバ経由のことも）
リクエスト ▶
◀ レスポンス（JSON）
⚙️ APサーバプログラム（Java・PHP・Python・Node.js など）が動く
3レスポンス（出力）＝ JSONデータステータスコード ＋ JSON本体
