JSON ／ JavaScript Object Notation（ジェイソン）

JSONってなに？ データの書き方のルール

ひとことで言うとJSON ＝
データを「名前: 値」の組み合わせで書く、
人にもコンピュータにも読みやすい文字のデータ形式 JavaScript から生まれたが、今はほぼすべての言語で使える共通の書き方（拡張子 .json）
"name": "傘"
1データ構造右の種類をクリックすると、該当する部分が光ります
product.json
{
"id": 1,
"name": "折りたたみ傘",
"price": 1980,
"inStock": true,
"colors": ["黒", "紺", "赤"],
"maker": {
"name": "雨具工房",
"country": "日本"
},
"discount": null
}

書き方のきまり

  • キー（名前）は必ず " ダブルクォートで囲む
  • 「キー」と「値」は :、項目どうしは , で区切る
  • 最後の項目のあとに , は付けない
  • コメント（メモ書き）は書けない

👍 メリット

  • ✅
    シンプルで人が読みやすいXML などより短く書ける
  • ✅
    ほぼすべての言語で使えるJava・Python・PHP など共通
  • ✅
    JavaScript と相性ばつぐんWebの画面でそのまま扱える
  • ✅

👎 デメリット

  • ⚠️
    コメントが書けない設定ファイルで説明を残しにくい
  • ⚠️
    書き方にきびしいカンマ1つの間違いで全体が読めない
  • ⚠️
    日付などの型がない日付は文字列で書くなど工夫が必要
  • ⚠️
    大量データだと重くなりがち毎回キー名を書くため（CSVより大きい）
